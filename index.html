📱 Telefona Nasıl Kurulur?

Bu uygulamayı GitHub Pages'e yükledikten sonra telefonunuzdan açarak tam ekran yerel bir uygulama gibi kurabilirsiniz:

  1. Telefonunuzun tarayıcısından (Chrome veya Safari) GitHub Pages linkinizi açın.
  2. Sağ üst köşedeki üç nokta (⋮) menüsüne dokunun.
  3. "Ana ekrana ekle" veya "Uygulamayı yükle" seçeneğini seçin.
  4. Uygulama telefonunuzun menüsüne eklenecektir!
